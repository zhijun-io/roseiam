# 运行环境与管理员初始化

- **状态：** Approved
- **审批记录：** 用户于 2026-10-20 确认本规格及全部 AC；批准进入 `sdd-plan`
- **版本：** 1.0
- **Spec ID：** IAM-OPS-01
- **父 PRD：** [IAM 管理平台 PRD](../../prd/iam-management-platform.md)，NFR-4、NFR-5

## 结果与范围

工程人员可在干净环境启动可重复的 IAM 后端运行环境，并安全创建首位 `PlatformAdmin`。本规格覆盖本地开发和最低限度的部署/初始化操作，不定义生产可用性目标。

**范围内**
- Docker Compose 本地运行后端、PostgreSQL 和 Mailpit。
- 版本化数据库迁移、健康状态检查和运行配置说明。
- 首次设置种入及一次性首位平台管理员初始化。
- 精确 CORS 来源配置、备份与恢复说明。

**范围外**
- 前端应用、生产云平台拓扑、高可用或灾备 RPO/RTO 承诺。
- 把 SMTP 密码加密密钥或其他生产秘密提交到仓库。

## 上游契约

- **设计就绪：** Ready — 设计评估覆盖 NFR-4、NFR-5；见 [B1 设计就绪评估](../../design/iam-domain.md#设计就绪评估)。

## 用户场景与验收条件

### UC-1 — 启动本地可运行环境

作为工程人员，我希望通过仓库提供的命令启动 IAM API、数据库和 Mailpit，以便在本地验证身份管理闭环。

- **AC-1：** 在满足文档列明前置条件的干净环境中，按仓库运行说明启动后，API、PostgreSQL 和 Mailpit 均可访问；Mailpit 收到的邀请/重置邮件可通过其本地界面查看。
- **AC-2：** 后端仅在数据库连接和必要初始化可用时报告就绪；数据库不可用时就绪检查失败，且错误响应不包含凭据或秘密。
- **AC-3：** 数据库结构由版本化迁移建立；重复启动不会依赖 Hibernate 自动建表或覆盖已有业务数据。
- **AC-4：** 本地 SMTP 默认指向 Mailpit（`mailpit:1025`），无认证、无 TLS；该配置明确标记为仅供本地开发。

### UC-2 — 初始化首位平台管理员

作为部署人员，我希望通过一次性初始化流程建立首位管理员，以便没有公开注册入口时仍能安全开始使用系统。

- **AC-5：** 系统尚无平台管理员且 `bootstrap-admin-email` 已配置时，启动初始化流程根据该配置值创建待验证邀请，并在事务提交后异步投递一次性验证链接；不创建共享默认密码，邮件投递失败不阻止应用启动。
- **AC-6：** 用户完成邀请验证并设置密码后成为活动 `PlatformAdmin`，邮箱标记为已验证。
- **AC-7：** 已存在活动 `PlatformAdmin` 时再次运行初始化不得覆盖用户、角色、凭据或现有设置，并以可辨识的“已初始化”结果结束。
- **AC-8：** 首次平台设置可由部署初始化配置种入；本地值为 `frontendBaseUrl=http://localhost:3000`、Mailpit SMTP 和 `no-reply@roseiam.local`。后续设置按 [平台设置契约](../../api.md#平台设置) 管理。

### UC-3 — 配置部署边界

作为部署人员，我希望只允许配置过的前端来源访问 API，并能按文档备份和恢复数据。

- **AC-9：** CORS 只接受部署配置的精确 origin；未配置来源和通配符来源均不能获得跨域访问许可；API 不使用跨域 Cookie。
- **AC-10：** 部署文档说明数据库备份、恢复步骤及 SMTP 密码加密密钥的独立保管/恢复要求；恢复后能够读取配置并验证关键 API 可用。
- **AC-11：** 主键按项目约定使用 `Long`，不使用 UUID；关系通过 ID 表达，schema 不创建外键约束，引用有效性由应用校验。

## 约束或验证说明

- 精确来源、SMTP 初始连接参数及 SMTP 密码加密密钥由部署配置提供；密钥不得放在 `PlatformSetting` 或版本控制中。
- 生产部署规模、可用性目标和备份频率目前没有 PRD 输入，AC-10 只要求可执行的说明，不声称特定 RPO/RTO。
- SMTP 外部发送不与数据库事务原子绑定；邮件发送失败不得伪装为已送达。重试行为依赖具体邀请/密码重置 API 契约。
- 当前 `BootstrapAdminRunner` 在启动流程中读取 `bootstrap-admin-email` 并调用创建邀请用例；邮箱未配置时跳过初始化。已有活动平台管理员时不变更数据；若邮箱已有待激活管理员，重新启动会撤销旧邀请并签发新邀请。邮件由提交后异步监听器 best-effort 投递；进程退出可能导致通知丢失，没有后台持久化或自动重试。
